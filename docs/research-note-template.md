# Research Note Template Rules

## Invariants

- The research note viewer/editor keeps the existing form structure.
- Layout lines, footer approval area, and overall A4 framing are treated as stable.
- Future design refinements may adjust styling, but should not replace the core structure without an explicit product decision.

## Auto-filled Defaults

- Author: the company member for the user currently updating the note
- Written date: the current update date
- Author signature: the current updater's saved signature, if available
- Reviewer: the project manager for the selected project
- Reviewed date: the current update date
- Reviewer signature: the project manager's saved signature, if available

## Editable Fields

- Author
- Written date
- Reviewer
- Reviewed date

These values are auto-filled when the note create/edit popup opens, but the user may change them before saving.
